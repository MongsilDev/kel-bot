# kel-bot

이터널 리턴 KEL 스크림의 팀 신청과 추첨을 관리하는 Discord 봇입니다.\
슬래시 명령 없이 채널에 올려 둔 대시보드 메시지 하나로 신청을 받고 매일 자동으로 추첨합니다.

## 기능

- 지역 단위 팀 신청.\
  서버 닉네임 `지역) 닉네임`에서 지역을 읽음
- 매일 0시 30분 1차 추첨.\
  정원이 모자라면 보류했다가 정원이 차는 즉시 추첨
- 17시까지 추첨이 성사되지 않으면 그날 스크림을 취소하고 다음 날로 바로 넘어감
- 떨어진 팀에 다음 날 우선권 자동 발급.\
  우선권 팀은 다음 추첨에서 먼저 뽑히고, 우선권은 그날 하루만 유효
- 14팀 이상 모이면 8팀을 뽑는 대신 전원을 두 중대로 나눠 편성
- 대시보드 버튼으로 신청, 취소, 우선권 수동 관리

## 동작 방식

하루 주기는 21시 초기화, 0시 30분 추첨, 17시 마감 순서로 돕니다.\
상태는 DB 없이 `data/` 아래 JSON 파일에 저장하며, 임시 파일에 먼저 쓰고 원래 파일과 교체하므로, 쓰는 도중 봇이 종료되어도 파일 내용이 손상되지 않습니다.\
봇이 꺼져 있던 동안 놓친 초기화, 추첨, 마감은 다시 켤 때 한 번씩만 처리합니다.

## 실행

```bash
pip install -r requirements.txt
cp .env.example .env   # 값 채우기
python main.py
```

## 설정

| 키 | 설명 |
|---|---|
| DISCORD_TOKEN | 봇 토큰.<br>필수 |
| APPLY_CHANNEL_ID | 대시보드를 띄울 채널 ID.<br>필수 |
| RESET_HOUR | 하루 초기화 시각.<br>기본 21 |
| DRAW_HOUR | 1차 추첨 시각의 시.<br>기본 0 |
| DRAW_MINUTE | 1차 추첨 시각의 분.<br>기본 30 |
| DEADLINE_HOUR | 신청 마감 시각.<br>기본 17 |
| TEAM_SLOTS | 추첨으로 뽑는 팀 수.<br>기본 8 |
| SENTRY_DSN | Sentry DSN.<br>선택.<br>비어 있으면 이벤트를 보내지 않음 |
